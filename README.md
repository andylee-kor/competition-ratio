# 수시 경쟁률

진학어플라이 학교 목록에서 학교별 공개 경쟁률을 조회하는 단일 페이지 앱입니다. 지원 목록은 브라우저 localStorage에 저장됩니다.

## 실행

Node.js 22.12 이상과 curl이 필요합니다.

```sh
npm install
npm run dev
```

http://localhost:5173 에서 사용합니다. 다른 포트는 `PORT=5174 npm run dev`로 지정합니다. 인터넷 연결이 필요하며 서버는 외부 접속을 받을 수 있도록 `0.0.0.0`에 바인딩합니다.

```sh
npm run build
npm start
npm test
```

브라우저 검증: 서버 실행 후 `npx playwright install chromium`, `node tests/browser.mjs`.

## 데이터

- 메인 페이지의 `hdnResultNow` JSON에서 수시 학교 목록과 실제 링크를 가져옵니다.
- 진학어플라이, 유웨이의 표 헤더와 전형 제목을 읽고 병합 셀을 복원합니다. EUC-KR도 처리합니다.
- 대학 자체 사이트는 같은 표 구조일 때 조회됩니다. 다른 형식이나 미공개 페이지는 오류 상태와 원문 링크로 표시합니다.
- 학교 목록은 1시간, 경쟁률은 1분 동안 서버 메모리에 캐시합니다. 화면 자동 조회는 5분 간격이며 숨겨진 탭에서는 중단합니다.
- 원문에 명시된 최종 현황만 최종으로 표시합니다. 접수 종료 시각이 지나도 자동으로 최종 처리하지 않습니다.
- 지원 목록 저장 키는 `admission-ratio:watchlist:v1`입니다. 브라우저 또는 실행 주소가 달라지면 별도 목록을 사용합니다.
- 서버에 지원 목록이나 사용자 데이터베이스를 저장하지 않습니다.
